# Audit & Certification

QAA SI will use multiple layers of security verification. Automated scanners can provide useful public checks before launch, while an independent manual audit remains a separate future step.

## Automated security scans

The following automated checks are planned once the final token contract is deployed and verified. Results and public report links will be added here when available.

| Verification        | Purpose                                                                                      | Status                                         | Report / verification link     |
| ------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------ |
| **GoPlus DeepScan** | Automated token and smart-contract risk checks, including permissions and common token risks | **Planned — after token deployment**           | `TBD — add public report link` |
| **TokenSniffer**    | Public token risk and contract checks                                                        | **Planned — after token deployment**           | `TBD — add public report link` |
| **Audit Forge**     | Automated Solidity security analysis and pre-audit checks                                    | **Planned — before / after final deployment**  | `TBD — add scan report link`   |
| **Web3defender**    | Additional token and wallet security checks                                                  | **Planned — after wallets and token are live** | `TBD — add verification link`  |

{% hint style="info" %}
These checks are **automated security scans**, not independent manual audits or certifications. Each completed scan will be linked publicly so the result can be reviewed independently.
{% endhint %}

## Independent audit

A separate independent smart-contract audit is planned after the token contract has been created and finalized.

| Independent review                           | Status                                      | Official report                   |
| -------------------------------------------- | ------------------------------------------- | --------------------------------- |
| **CertiK or comparable independent auditor** | **Planned — after token contract creation** | `TBD — add official audit report` |

The independent audit scope is expected to cover the final token contract and any additional smart contracts considered security-critical at launch.

Once an independent audit has been completed, this page will be updated with the official auditor, report, scope, completion date and verification link.

{% hint style="warning" %}
QAA SI will only describe a contract as **audited** or **certified** when an official, independently verifiable audit or certification report exists. Automated scanner results will remain clearly labeled as automated security checks.
{% endhint %}

## Verification standard

Where available, this page will publish direct links to the deployed contract on BaseScan, automated scan results, relevant wallet verification records and any future independent audit report so that security claims can be checked publicly.
