# Risks & Disclaimer

SIN.AI combines emerging technologies, including artificial intelligence, external software integrations and blockchain systems. Each introduces material technical, operational and economic risks.

## Key risk categories

| Risk                          | Description                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------- |
| **AI reliability**            | Models can produce incorrect, incomplete or misleading outputs.                               |
| **Tool execution**            | External APIs or integrations can fail, change behavior or return unexpected results.         |
| **Smart contracts**           | Deployed code can contain defects, vulnerabilities or unintended economic behavior.           |
| **Wallet security**           | Lost keys, compromised credentials or malicious signing requests can cause irreversible loss. |
| **Blockchain infrastructure** | Congestion, outages, bridge failures or network-level events can disrupt operations.          |
| **Liquidity & volatility**    | Digital-asset markets can experience extreme price movements and limited liquidity.           |
| **Regulatory change**         | Applicable laws, classifications and compliance obligations can evolve across jurisdictions.  |

## User responsibility

Users should independently evaluate relevant risks, verify official contract information and understand transaction consequences before interacting with blockchain components.

{% hint style="danger" %}
Do not send funds or sign transactions based only on an unverified address, social-media post, direct message or third-party listing. Confirm official deployment information against SIN.AI documentation.
{% endhint %}
